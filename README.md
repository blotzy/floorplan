# Accosting rebuild: floor plan and design wishlist

220 Laurel Dr, Altadena. All-electric, single-story Eaton Fire rebuild. Updated Oct 14, 2026 · @Richard

![Site plan](renders/schematic.png)

*Owner schematic, not for construction: the full lot with the house, carport, courtyard, fences and a true-north arrow (about 22° off plan north). Street (plan north) at the bottom, carport (plan east) on the left.*

![Floor plan, house only](renders/schematic-zoom.png)

*The house at a larger scale.*

Walls are drawn at realistic thicknesses: exterior 9" (2x6 + sheathing + 1" rigid insulation + stucco), interior 4½", plumbing walls 6½". Room sizes on the drawing are clear dimensions, finish face to finish face. Sizes and fine details are the architect's call; the drawing shows one way the [wishlist](#design-wishlist-by-trade) fits.

## Survey overlay

![Survey overlay](renders/survey-overlay.png)

*The topographic survey (`source_files/survey/`) over the schematic: existing walls, the old chimney, paving, fences, trees and utilities in colour; spot elevations in orange; 1' contours in brown. The site falls about 4 ft across the house from the carport end to the primary-suite end. See [site existing conditions](docs/03-site-and-landscape.md#existing-conditions-survey). Combined DXF: `Accosting - owner schematic + survey.dxf`.*

## 3D massing model

**[Open the 3D model](https://blotzy.github.io/floorplan/renders/3d/house.html)** (GitHub Pages; GitHub's file view only shows the source). From a local clone, open `renders/3d/house.html` in a browser instead. It has orbit, zoom, toggle ceiling/furniture, a sun-position control, and a **Walk** button for eye-level navigation (WASD + mouse on a computer; on a phone or tablet, a joystick to move and drag to look). The same geometry is in `renders/3d/house.obj` for Windows 3D Viewer or Blender.

## Files

| File | What it is |
| --- | --- |
| `Accosting - owner schematic.dxf` | The plan as a DXF (inches), generated by `scripts/schematic.py` |
| `scripts/schematic.py` | Draws the plan; every wall, door and window is a number at the top. `uv run scripts/schematic.py` |
| `scripts/make_3d.py` | Builds the 3D model from the schematic. `uv run scripts/make_3d.py` |
| `scripts/survey_overlay.py` | Overlays the survey on the schematic (`renders/survey-overlay.png`, `Accosting - owner schematic + survey.dxf`). `uv run scripts/survey_overlay.py` |
| `source_files/survey/` | Topographic survey (DWG, DXF, PDF) |
| `scripts/experiment_exterior.py` | Exterior style alternatives (roof form, eaves, colours) on the 3D model (`renders/experiments/`) |
| `scripts/experiment_utility_layouts.py` | Common bath and laundry block with the mech closet moved behind the bath and the washer/dryer in the mech closet's spot (`utility-swap.png`) |
| `scripts/experiment_south_windows.py` | Dining and kitchen windows on the south wall: three equal windows (main plan), the earlier 10' pair, matched sills, a ribbon, and floor-to-head dining windows (`south-windows-compare.png`, plus a 3D model each) |
| `renders/` | Plan renders and the 3D model |

Viewing and measuring: open the DXFs in QCAD (View → Auto Zoom; Snap → Endpoint; Info → Distance). Units are inches.
